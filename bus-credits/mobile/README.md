# تطبيق الجوال — رصيد الباص (Expo React Native)

تطبيق واحد لأندرويد و iOS، شريط تبويبات سفلي، يركّز على:
- 🧭 **تخطيط الرحلة مع التبديل** (عنوان → عنوان، حتى لو احتاج تبديل خطوط).
- ⭐ **الخطوط المفضّلة** (إضافة/حذف، تظهر محطّاتها).
- 🎫 **تذكرة QR** أصلية (`react-native-qrcode-svg`) تُعرض للسائق/جهاز التدقيق، مع تتبّع حالة التذكرة.
- 💳 **الرصيد والشحن** عبر شام كاش (محاكاة) + ركوب رحلة.
- 🚌 **الباصات القريبة** في الاتجاهين (ذهاب/إياب) مع المسافة والوقت.

## المتطلبات
- Node 18+
- تطبيق **Expo Go** على هاتفك (من App Store / Google Play)، أو محاكي.
- تشغيل خادم الـ API (مجلد `bus-credits`): `npm install && npm run seed && npm start`

## الإعداد المهم: عنوان الخادم
عدّل `src/config.js` وضع عنوان الخادم:
- هاتف حقيقي عبر Expo Go: `http://<IP-الكمبيوتر-المحلي>:4000` (نفس شبكة WiFi).
- محاكي أندرويد: `http://10.0.2.2:4000`
- محاكي iOS: `http://localhost:4000`
- خادم منشور: `https://...`

> لمعرفة IP الكمبيوتر: على لينكس/ماك ` hostname -I ` أو `ipconfig getifaddr en0`، على ويندوز `ipconfig`.

## التشغيل
```bash
cd mobile
npm install
npx expo install     # يضبط إصدارات الحزم مع إصدار Expo
npx expo start       # امسح رمز QR بتطبيق Expo Go
```
